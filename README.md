# 🔥 Amber

**Amber** is a custom pixel-art dark fantasy desktop rice inspired by Dark Souls, classic RPG interfaces, and the atmosphere of a bonfire.

Designed for **CachyOS + KDE Plasma 6 + KWin + Wayland**, using **Quickshell** as the main desktop UI layer.

*Praise the Sun! \\[T]/*

## Design philosophy

Amber combines modern desktop usability with pixel-art aesthetics, dark fantasy elements, warm ember colors, and subtle animations.

The project features two visual modes:

- **Bonfire Dusk** — warm, golden, firelit atmosphere.
- **Ember Moon** — darker, cooler, moonlit atmosphere.

Both modes remain dark themes.

## Theme Bank

Amber provides 10 interchangeable color palettes.

| Bonfire Dusk (Day) | Ember Moon (Night) |
|---|---|
| First Flame | Dying Ember |
| Anor Londo | Moonlit Cathedral |
| Ashen Pilgrim | Abyss Watcher |
| Moss & Ember | Hollow Grove |
| Crimson Covenant | Eclipse of Fire |

The Theme Bank is designed to allow switching palettes directly from the top panel without restarting the desktop shell.
